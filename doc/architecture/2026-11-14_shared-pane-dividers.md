# Shared pane dividers

All resizable workspace dividers are created by `WindowLayout.pane`. It applies the `workspace-divider` class and GTK's wide handle to every pane, in either orientation. The class identifies the group; divider appearance remains native to the active GTK theme. The shared factory measures native separator padding without its own class, then adds 2px of padding on each side across the handle thickness (left/right for a horizontal split, top/bottom for a vertical split). This avoids replacing Mint-X’s existing padding and expands the native input window by 4px and retains the theme grip, hover and keyboard behavior. Do not add pane-specific separator styling, since equal handle dimensions alone do not ensure equal appearance or hover behavior.

The native UI regression compares rendered divider pixels and handle dimensions across the overview, target editor, target editor, and workspace panes in Adwaita and Mint-X light and dark themes. Mint-X supplies its dot grip from its own GTK theme assets; keeping the native wide handle preserves the desktop’s existing grip instead of drawing a separate overview grip. It also exercises the overview handle's mouse, keyboard, and persistence behavior. A native regression compares padded and unpadded input-window thickness in each theme and drags every handle from the outermost added pixel. Pointer coordinates come from the handle window's actual screen origin; pane position alone does not include the theme's handle offset.
